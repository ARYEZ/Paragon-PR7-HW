# Changelog

## 0.1.0

- First release: hardware information, the way HWiNFO and CPU-Z show it.
- System Summary: CPU (caches, instruction sets), motherboard, BIOS, TPM, memory modules, graphics (real video
  memory), monitors, drives with health and temperature, Windows, network.
- Details tree with every device's properties, drive health (S.M.A.R.T.) as administrator.
- Sensors with Current / Min / Max / Average and two-minute graphs; GPU counters, nvidia-smi, drive temperatures,
  ACPI thermal zones; Reset Min / Max, Log to CSV.
- Report, Copy, As Admin, Options; OBSIDIAN and AURORA finishes; Check for Updates.
